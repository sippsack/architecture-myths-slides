# Walking Skeleton

- Demonstriert Tragfähigkeit des Architekturansatzes
- “Intended to grow, Permanent Code”
- für produktiven Einsatz entwickelt
- verbindet (unvollständige) Bausteine auf belastbare Weise
- Abgrenzung zu:
  - Spike / Durchstich
  - Prototype

<blockquote>
    <p style="font-style: italic">"A Walking Skeleton is a tiny implementation of the system that performs a small <strong>end-to-end function</strong>. 
    It need not use the final architecture, but it should link together the main architectural components. 
    The <strong>architecture and the functionality can then evolve in parallel.</strong>"</p>
    <cite>- Alistair Cockburn</cite>
</blockquote>
