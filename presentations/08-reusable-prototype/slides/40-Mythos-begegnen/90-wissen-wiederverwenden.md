# Wie begegnen wir dem Mythos?

## **Prototyping:** Erkenntnisse aufbauen

Prototyp soll zeigen, dass Idee funktioniert, z.b.
- Verwendung bestimmter Technologie
- Anwendung eines Patterns
- Eignung einer Bibliothek, Framework oder Komponente
- ...
